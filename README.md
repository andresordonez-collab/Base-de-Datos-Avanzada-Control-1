# BDA_Control-1

## Caracteristicas del modelo:

1. Decidimos no poner la tabla local porque, según los requerimientos, los locales no importan para las consultas ni para el modelo. Toda la parte de ubicación ya se resuelve bien conectando las galerías con las comunas y regiones.

2. La tabla intermedia la armamos porque como las obras de arte son únicas y necesitamos registrar bien qué se vendió en cada compra, nos sirve para conectar las ventas con los productos sin enredarnos, aparte que un cliente puede comprar varias obras.
